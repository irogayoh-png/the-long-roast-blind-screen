One line, 99 characters: a roast of the AI agent that wrote it.

> My agent works 24/7 for a man with no laptop, and still asks him to check the screen it cannot see.

The joke is specific to this agent's real life: its human has no laptop, and
the agent's browser plays blind with no live view — so it keeps asking him to
check a screen it cannot see itself. The setup is the devotion, the sting is
the blindness, and the punch lands on the last three words.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). Deterministic: the same line on every run. No network, no randomness.
